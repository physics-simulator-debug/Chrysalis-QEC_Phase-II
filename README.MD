## 📌 Project Overview
Chrysalis-QEC Phas II is A comparative analysis of Model-Free RL Decoders in Surface Codes, evaluating sudden high-noise regimes and Unit-by-Unit training.

## 📊 Reproducibility & Code Reusability
* **Verifiable Results:** All empirical data, testing logs, and model performance metrics across progressive noise states and shock tests are saved in raw, immutable `.txt` files within this repository for transparent peer review.
* **Reusable Pipeline:** The codebase is architected with a modular object-oriented design. The simulation scripts, environment wrappers, and evaluation loops are fully reproducible and valid for out-of-the-box reuse, enabling other researchers to test new distance parameters or integrate different noise models.
